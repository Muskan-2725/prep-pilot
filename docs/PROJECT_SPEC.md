# Product specification
Target users are self-directed GATE CSE candidates who need a consistent mentor rather than generic chat. The MVP promise is an explainable learning loop: collect only preparation inputs, prioritize measured weak topics, teach, assess, and update a persistent topic state.

**MVP scope:** email/password authentication, GATE CSE-only onboarding, conversational tutor, curated practice, deterministic evaluation diagnoses, adaptive plan versions, learner profile, and source-aware research response. **Out of scope:** payments, public deployment, uploads, real-time collaboration, claims of live/current exam details, and broad exam support.

Acceptance path: sign up; save GATE CSE profile; generate plan; ask about deadlocks; request practice; submit answer; observe diagnosis/mastery; regenerate plan. Main risks are stale exam facts, overconfident AI feedback, weak question coverage, and sensitive account data. The MVP mitigates the first two by offline curated content and explicit uncertainty.
